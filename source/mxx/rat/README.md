# `RAT`
> random access texts (training example to implement command-line utility similar to gnu-utils `cat`)

## arguments

- with lower letter like `-n` `-l`: enable functionality that are off by default
- with upper letter like `-R` `-P`: disable functionality that are on by default

- `-P [0,100]`: disable percentage (show full file contents) without specifying percent value range, or with value specified randomly chooses to show percentage of lines
- `-n`: enable display line numbers
